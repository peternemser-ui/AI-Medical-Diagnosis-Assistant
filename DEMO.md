# MedDiagnose AI -- Demo Script

A 10-minute walkthrough for presenting the platform to stakeholders, investors, or technical reviewers.

---

## Setup (Before Demo)

1. **Start the backend**
   ```bash
   cd backend
   python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```
2. **Start the frontend**
   ```bash
   cd frontend
   npm run dev
   ```
3. **Verify** both services are running:
   - Frontend: http://localhost:3000
   - Backend health check: http://localhost:8000/health
4. **Login as admin** (or create an account if first run)
5. **Clear previous diagnosis history** so the demo starts clean
6. **Confirm** the Anthropic API key is configured (check Settings or `.env`)

---

## Demo Flow (10 minutes)

### Act 1: First Impression (2 min)

1. **Open the landing page** at http://localhost:3000
   - Point out the "Powered by 7 Autonomous AI Agents" badge
   - Highlight the specialist team section and trust indicators
   - Note the clean, medical-grade design with Tailwind CSS

2. **Click "Start Consultation"**
   - Show the login/signup flow (JWT authentication)
   - Log in and arrive at the consultation view

3. **Introduce Dr. Hopps**
   - The animated avatar tracks the cursor and blinks
   - Mention it provides visual feedback during the conversation (listening, thinking, speaking states)

### Act 2: Medical Consultation (3 min)

1. **Type a realistic symptom description:**
   > "I have a persistent headache for 2 weeks, mostly on the right side. Throbbing pain, rated 6/10. Light sensitivity and nausea."

2. **Watch the agent pipeline indicator** light up in real time
   - Triage processes urgency and red flags
   - Diagnostician and Research run in parallel
   - Specialist (Neurology) provides domain-specific analysis
   - Treatment generates recommendations
   - Safety checks for contraindications
   - Empathy translates to patient-friendly language

3. **Answer follow-up questions** from the specialist agent
   - These are AI-generated to narrow the differential diagnosis

4. **(Optional) Upload a photo**
   - Demonstrate the annotation tools: circle an area, add arrows, draw freehand, type labels
   - Show how the image agent processes the upload

5. **Show the body diagram**
   - Click on the head region to add symptom location context
   - Note the visual feedback when areas are selected

### Act 3: Diagnosis Results (2 min)

1. **Review the streaming diagnosis output**
   - Results appear progressively as each agent completes
   - The pipeline indicator shows real timing per agent

2. **Explore the DiagnosisCard**
   - Primary diagnosis with confidence percentage and ConfidenceRing visualization
   - Alternative diagnoses ranked by probability
   - Red flags highlighted with urgency indicators

3. **Expand "Clinical Reasoning"** on the top diagnosis
   - Show the evidence trail: which agent contributed what
   - Point out Bayesian reasoning and clinical scoring (e.g., HEART score, PHQ-9)

4. **Show the "What to Tell Your Doctor" card**
   - Patient-friendly summary generated by the Empathy agent
   - Actionable next steps with clear language

5. **Download the PDF report**
   - Structured clinical document with medical disclaimers
   - Suitable for sharing with a healthcare provider

### Act 4: Business Features (2 min)

1. **Show the Pricing page** (`/pricing`)
   - Four tiers: Free, Plus, Pro, Family
   - Stripe integration for payment processing

2. **Navigate to the Admin Dashboard** (`/admin`)
   - **Overview**: KPIs, consultation volume, agent performance metrics
   - **Agents**: Real-time health status of all 7+ agents with derived status indicators
   - **Analytics**: Funnel tracking and conversion metrics
   - **Cases**: Review queue for quality assurance

3. **Run a Quality Audit** (Admin > Improve)
   - The self-learning Quality Auditor reviews past diagnoses
   - Identifies systematic weaknesses and suggests improvements

4. **Show Model Comparison** (Admin > Model Compare)
   - Side-by-side comparison of Claude, GPT-4o, Gemini, and Ollama
   - Demonstrates multi-provider flexibility

5. **Show Billing config** (Admin > Billing)
   - Stripe integration, subscription management, referral tracking

### Act 5: Technical Depth (1 min)

1. **Show the System Insight Dashboard** (Admin > System)
   - Feature flags for controlled rollouts
   - Pipeline visualization showing agent execution flow
   - Real-time SSE streaming architecture

2. **Show the Developer Portal** (Admin > Developer Portal)
   - API-as-a-Service documentation
   - Key management for external integrators

3. **Mention infrastructure highlights:**
   - Docker Compose deployment with PostgreSQL + Redis
   - 12-language internationalization
   - PWA with offline mode
   - JWT + Fernet encryption for security
   - Rate limiting on all endpoints

## Troubleshooting During Demo

| Issue | Quick Fix |
|-------|-----------|
| Backend not responding | Check `http://localhost:8000/health` -- restart uvicorn if needed |
| "No API key" error | Open Settings panel, enter an Anthropic key, or check `backend/.env` |
| Agents timing out | The first request after cold start is slower -- warm up with a test query before the demo |
| Avatar not animating | Hard-refresh the page (Ctrl+Shift+R) to reload assets |
| PDF download fails | Ensure the browser allows popups from localhost |

## Post-Demo Questions to Anticipate

1. **"Is this HIPAA-compliant?"** -- The architecture supports encryption at rest (Fernet), JWT auth, security headers, and audit logging. A HIPAA agent exists for compliance checks. Full compliance requires additional operational controls (BAA, hosting, etc.).

2. **"How accurate is the diagnosis?"** -- The system produces differential diagnoses with confidence scores, not definitive diagnoses. The Quality Auditor provides ongoing accuracy tracking. Clinical validation with real-world data is a planned milestone.

3. **"Can it integrate with our EHR?"** -- An EHR agent (`ehr_agent.py`) is included for integration scaffolding. FHIR-compatible interfaces can be extended.

4. **"What about liability?"** -- Every output includes a medical disclaimer. The system is positioned as a clinical decision support tool, not a replacement for physician judgment.

5. **"How does pricing work for B2B?"** -- White-label theming, tenant isolation (`tenant_agent.py`), and API-as-a-Service are built in. Custom pricing is available for clinic deployments.
